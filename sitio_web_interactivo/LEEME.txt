SITIO WEB INTERACTIVO

Archivos:
- index.html
- blog.html
- evento.html
- noticias.html
- styles.css
- script.js

IMPORTANTE:
El proyecto utiliza fetch() en JavaScript para cargar los archivos HTML
dinámicamente.

Para probarlo correctamente en Visual Studio Code:

1. Abre la carpeta completa del proyecto.
2. Instala la extensión Live Server si todavía no la tienes.
3. Haz clic derecho sobre index.html.
4. Selecciona "Open with Live Server" / "Abrir con Live Server".
5. Prueba los botones Blog, Evento y Noticias.

Antes de entregar:
Renombra la carpeta comprimida con el formato solicitado por la docente:
CURSO-MÓDULO-APELLIDO NOMBRE
